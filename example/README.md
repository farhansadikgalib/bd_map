# bd_map example

Demo app for the [bd_map](https://pub.dev/packages/bd_map) package.

- **Explore**: `BdMap`, tap to drill from division down to union.
- **Atlas**: `BdCountryMap`, the whole country at one level.
- **Classic**: the original `Bangladesh` division map.

The app bar switches between a JSON asset and an API-style response as the
data source, and toggles English and Bangla names. See `lib/main.dart`.

```sh
flutter run
```
